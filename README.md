# BioCard NFC - Editable Profile (Vanilla JS)

## Mô tả
Project này là một trang Bio NFC profile hoàn chỉnh bằng **HTML, CSS, JavaScript thuần**.  
Tính năng nổi bật:
- Giao diện hiện đại, phong cách đỏ + trắng, có hiệu ứng sunburst, gradient, noise, shadow.
- Avatar PNG nền trong suốt, không cắt tròn, có drop shadow và animation.
- Chữ nền lớn (outline) tự động lấy từ `profile.name`.
- Thanh đỏ chéo với marquee chạy vô hạn.
- Phần thông tin, liên hệ, mạng xã hội tự render từ `profile.js`.
- **Admin panel** (client-side) để chỉnh sửa thông tin trực tiếp trên web.
- Dark / Light mode.
- Tạo file `contact.vcf` (Lưu danh bạ).
- Tạo QR code offline (mẫu đơn giản).
- Responsive cho Desktop / Tablet / Mobile.
